This project treats each post as an **MDX file** under `content/posts/`. Write in Markdown; drop assets in `public/images/` and reference them with usual image syntax—similar to Notion exports or Substack, with room for LaTeX via fenced `math` blocks or display equations below, plus fenced code when you need it.

## Display math

Below is variance written in display form (inline math in prose is simplest as single-dollar delimiters on one line):

$$
\operatorname{Var}(X) = \mathbb{E}\bigl[(X - \mathbb{E}[X])^2\bigr]
$$

## Code blocks

```typescript
type Reliability = {
  tailRisk: number;
  averageCase: number;
};

export function summarize(model: Reliability): string {
  return `tails: ${model.tailRisk}, avg: ${model.averageCase}`;
}
```
